Student project

The starter includes the HTML scaffold, CSS and JavaScript work areas, anonymous GeoJSON and intermediate checkpoints. Extract it before editing.

Download student starterDownload GeoJSON data

Run the student project

  1. Open the extracted starter folder in VS Code.
  2. Open a terminal in that folder and use the command for your operating system.
  3. Visit http://localhost:8000, or the address supplied by Live Server.
Local server commands
python3 -m http.server 8000

# Windows with the Python launcher
py -m http.server 8000

If port 8000 is already used, choose 8001 and update the address in the browser. Stop the server with Ctrl+C. Do not open the project as a file URL when loading GeoJSON with fetch.

Intermediate checkpoints

Replace starter/app.js with checkpoints/02_map.js after Lab 2 or checkpoints/03_markers.js after Lab 3 when you need a reference. Keep one map script loaded at a time.

Prepare a new workbook export

The optional converter is included with the starter download. It requires Python and openpyxl and targets the supplied survey sheet and header structure. Review it before using a revised instrument.

Optional workbook conversion
python3 -m pip install openpyxl
python3 prepare_geojson.py survey.xlsx --output starter/data/farms.geojson

Internet and data access

Course reading pages use only local assets. The map demo loads Leaflet and tiles from external services. For an offline classroom, prepare permitted local assets in advance. Exact survey coordinates can still require controlled sharing even when names are excluded.
