Submission requirements and marking

Submit

• Your project folder with index.html, styles.css, app.js and data/farms.geojson.

• Three screenshots: all records, a filtered result and the narrow-screen layout.

• A test log showing actions, expected results, actual results and fixes.

• A 300-500 word explanation of coordinate order, the workbook join, count meaning, data limits and privacy.

Criterion Marks Evidence
Structure and usability 15 Labels, valid ids, clear controls
Responsive CSS 15 Map height, mobile layout, focus states
Map and data loading 20 Real GeoJSON points, popups, attribution
Filtering and selection 25 Combined controls, consistent counts and details
Data interpretation 15 Correct record/response meaning and quality notes
Testing and explanation 10 Test log, error handling and oral explanation
Total 100

Extension tasks

Choose one after the core passes: add a records table using the same visibleFeatures array; add a second permitted basemap with attribution; introduce marker clustering while preserving record counts; or compare point locations with verified administrative boundaries. Explain and test the added behaviour.

Instructor prompts

Ask a student to explain why a selected district cannot imply a point has been spatially validated. Then ask them to trace one search action from event handler to filter predicate to map redraw.

Resolve problems and review the sources

Symptom First check or correction
HTTP 404 for GeoJSON Serve the correct folder; check data/farms.geojson spelling
Fetch fails from file URL Use the local HTTP server or Live Server
L is not defined Check CDN request and Leaflet-before-app script order
Blank or collapsed map Confirm #map height and tile requests
Points far from Zanzibar Check coordinate order and source CRS
Old markers remain Clear farmLayer before addData
Zero results after filtering Check exact activity values and reset controls
Counts differ from source Distinguish location count and distinct response ids
Port already in use Use port 8001 and browse localhost:8001
Area shows an assumed unit Use the supplied unit-unspecified label
