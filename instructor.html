Building the Zanzibar Aquaculture Atlas

These notes teach students to turn aquaculture survey locations into an interactive web atlas. The lab pages follows the same concepts and provides code, checkpoints and an assessment. The result is a small teaching version of the atlas, with a map, filters, result list and selected-record details.

Audience and learning outcomes

Designed for undergraduate GIS or computing students with basic computer skills and some exposure to programming. Students new to JavaScript should practise variables, arrays and functions before Lab 3.

• Build a semantic HTML page and a responsive CSS layout.

• Explain how JavaScript changes the page and responds to user actions.

• Display GeoJSON survey points in Leaflet and filter them.

• Distinguish location records from survey responses and explain data limits.

• Debug loading, coordinate and interaction problems.

Teach and assess the whole workflow

Suggested delivery

Before class, verify internet access, Python 3 or Live Server, and the GeoJSON file. Demonstrate one failure intentionally in each session: a missing HTML id, zero map height, a filename error, reversed manual coordinates, a stale layer, and a no-match filter. Students should diagnose the failure before receiving the correction.

Short review answers

• HTML defines structure, CSS presentation, JavaScript behaviour, and Leaflet map operations.

• Leaflet manual positions use latitude then longitude; GeoJSON Point arrays use longitude then latitude.

• 437 counts repeat-location records; 301 counts linked survey responses.

• Shared coordinates do not by themselves prove duplicate farms.

• textContent displays a survey answer without interpreting it as HTML.

• A failed HTTP request should produce an error, not a misleading empty dataset.

Assessment

Use the 100-mark rubric in the assessment page. Ask each student to explain one filter predicate, one data-quality concern and the coordinate-order difference. Award functionality marks based on demonstrated behaviour, not screenshots alone.
