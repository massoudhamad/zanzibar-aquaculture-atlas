Work with records and functions

JavaScript connects the survey data to the interface. A feature is an object. Its properties contain descriptive attributes, and its geometry contains the location. An array stores many features.

Code example
const farm = {
  id: 'ZF-0001',
  type: 'Seaweed Farm',
  village: 'BUNGI'
};
const features = [farm];
const seaweed = features.filter(f =>
  f.type === 'Seaweed Farm');
console.log(seaweed.length);

This shortened object demonstrates JavaScript syntax; it is not a full GeoJSON feature. const protects the variable binding from reassignment, while let is appropriate for a variable whose value will be reassigned. Objects and arrays held by const can still be changed.

Functions make the workflow reusable

A function groups instructions that perform one task. In the teaching atlas, render recalculates the matching records and redraws the map and list. showDetails displays one record. fitResults changes the map extent.

Compare data deliberately

Use === for exact comparisons. A district filter compares the selected district with the record district. Search is different: both the query and the village text are converted to lowercase, then includes checks whether the query occurs inside the text.

Missing values

A missing measurement should not silently become zero. The expression value ?? "Not reported" substitutes a label only when value is null or undefined. A real zero remains visible.

Practice

Create three example objects and use filter to find one activity. Explain the difference between map, which transforms each item, and filter, which selects items.

Connect user actions to the data

The Document Object Model represents the page as objects that JavaScript can read and change. getElementById returns one element. textContent updates its visible text. addEventListener runs a function when a user action occurs.

Code example
const search = document.getElementById('search');
search.addEventListener('input', render);

const row = document.createElement('p');
row.textContent = 'Village: ' + farm.village;
document.getElementById('detail').append(row);

Pass render as the event handler; writing render() here would execute it immediately instead of registering it. The input event updates results as a person types, while change is suitable for a selection control.

Use text safely

Survey text should be displayed as textContent or as DOM nodes. Putting untrusted values directly into innerHTML can cause markup to be interpreted. The reference solution constructs popup content as a DOM element rather than assembling HTML from survey answers.

Keep one source of truth

allFeatures contains the loaded data. visibleFeatures contains the current filtered subset. The same subset supplies markers, the result list and counts. Updating only the markers would leave misleading statistics behind.

State changes to notice

When filters change, the selected detail panel is cleared because the previously selected record may no longer be visible. Reset clears all three controls, renders the complete set, and fits the map extent.

Instructor question

What would happen if render cleared the list but forgot to clear the existing marker layer? Explain why markerById is also cleared before drawing new markers.
