Understand coordinates and GeoJSON

A web map combines a basemap with geographic overlays. Raster tiles provide background imagery. Survey points are an overlay, so their presence does not imply that a basemap provider collected or validated the farm data.

Context Order Example
Leaflet manual position Latitude then longitude [-6.16, 39.38]
GeoJSON point geometry Longitude then latitude [39.38, -6.16]

GeoJSON Point coordinates use longitude and latitude in decimal degrees under the geographic system defined by RFC 7946. Leaflet converts GeoJSON positions for display. Do not manually swap the coordinates when passing a valid FeatureCollection to L.geoJSON.

Code example
{
  "type": "Feature",
  "geometry": {
    "type": "Point",
    "coordinates": [39.38, -6.16]
  },
  "properties": {
    "id": "DEMO-001", "type": "Seaweed Farm"
  }
}

DEMO-001 is illustrative and is not a survey record.

Coordinate reference systems

Geographic degrees are not metres. Do not put UTM eastings and northings into GeoJSON longitude and latitude fields. If coordinates are projected, transform them correctly before export. The common web basemap display uses Web Mercator; the GeoJSON source remains geographic longitude and latitude.

Check understanding

Which error would move a Zanzibar point far away: changing its colour, reversing its coordinates, or changing popup text? What additional evidence is needed to confirm a district assignment?

Build a map from layers

The teaching code is pinned to Leaflet 1.9.4. A map object manages the view. A tile layer supplies the background. A GeoJSON layer displays the survey features. Keeping these objects separate allows the survey layer to change without recreating the entire map.

Code example
const map = L.map('map').setView([-6.16, 39.38], 10);
const farmLayer = L.geoJSON(null).addTo(map);
farmLayer.addData(data.features);

const bounds = farmLayer.getBounds();
if (bounds.isValid()) map.fitBounds(bounds);

The empty GeoJSON layer can be populated after the data arrives. A bounds check prevents an empty result set from causing a failed extent change. Zoom is a display level, not a coordinate or a physical scale measurement.

Symbology and identification

Use different activity colours, a readable legend and a popup showing an anonymous farm code. Circle markers use a pixel radius, which stays visually consistent across zoom levels. A geographic circle instead uses a real-world radius.

Useful options in the project

Option or callback Role
pointToLayer Choose the symbol used for a Point feature
onEachFeature Attach a popup and click event
filter Decide which valid features may be drawn
clearLayers Remove the previous displayed features

Practice

Change the seaweed colour and update the legend to match. Then zoom in and out. Explain why two records at exactly the same coordinates can appear as one visible symbol.
