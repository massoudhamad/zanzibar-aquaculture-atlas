How the atlas reaches the browser

A browser requests a page from a web server. It reads the HTML, applies the CSS and runs JavaScript. In this project, JavaScript also requests a GeoJSON file and map tiles. The local Python server serves project files; it does not generate the map or replace the external tile service.

HTML Page structure and meaning Map container, labels, buttons

Separate the source files

Use index.html for the page, styles.css for design, app.js for behaviour, and data/farms.geojson for data. Relative paths are resolved from the page URL. A misspelled filename can produce an HTTP 404 error even when the file exists in another folder.

Load scripts in a predictable order

The supplied HTML uses defer on external scripts. The browser can continue parsing the page, then executes Leaflet before app.js. This allows the map container and controls to exist before JavaScript uses them.

Discuss

If farm points appear but streets do not, which part of this system probably failed? If the heading appears but the map is absent, which files and browser panels should you inspect first?

Give the atlas a clear structure

HTML describes content and controls. A heading identifies the atlas, an aside contains filters, and a section holds the map. A div is useful as a map container because Leaflet will manage its contents.

Code example
<label for="district">District</label>
<select id="district">
  <option value="">All districts</option>
</select>
<div id="map"></div>

The label for attribute matches the select id. This relationship makes the control easier to use. An id must be unique on the page. JavaScript finds the control with document.getElementById("district").

Attributes students should recognise

Attribute Purpose
id A unique page identifier used by CSS and JavaScript
class A reusable styling category
href A link destination or stylesheet address
src A script or image source
type The behaviour of a control such as search or button
aria-live Announces updated result text to assistive technology

Instructor activity

Ask students to add a labelled search box and a Reset button. Then deliberately change id="map" to id="farm-map" without editing the JavaScript. Have students predict the consequence and explain the correction.

Check understanding

Why use a visible label instead of relying only on placeholder text? Why should a clickable result be a button rather than a div with a click handler?
