CSS and responsive layouts

Lesson 21 hourRead, practise, check

Design a usable map workspace

CSS rules select elements and assign presentation properties. Layout should support the map task: filters remain easy to find, the map has measurable height, and text stays readable. Leaflet cannot display a useful map inside a container whose computed height is zero.

Code example
main {
  display: grid;
  grid-template-columns: 320px minmax(0, 1fr);
}
#map { height: 640px; }
@media (max-width: 700px) {
  main { grid-template-columns: 1fr; }
  #map { height: 440px; }
}

On a wide screen, the sidebar has a fixed width and the map takes the remaining space. Below 700 pixels, the columns become one vertical stack. minmax(0, 1fr) allows the map column to shrink without forcing overflow.

The box model

Content, padding, borders and margins all affect the space an element occupies. Setting box-sizing: border-box makes specified widths include padding and borders. This helps prevent inputs from extending beyond the sidebar.

Readable and accessible controls

Use visible focus styles so keyboard users can find the current control. A legend must include activity names as well as colours. Test a narrow screen and browser zoom at 200 percent; check that controls remain reachable and text does not overlap.

Practical exercise

Change the sidebar width from 320 to 260 pixels. Explain which elements are affected. Then remove #map height temporarily, observe the result, and restore it.
