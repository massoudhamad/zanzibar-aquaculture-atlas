Join the workbook without inflating counts

The supplied export has a main response sheet and a repeat-location sheet named group_gy0jc35. A survey response can have multiple locations. The repeat sheet holds the usable farm GPS fields; the main sheet farm GPS fields are empty in this export.

Main response sheet Repeat-location sheet
_index identifies the response _parent_index links to that response
District, village and ownership Type of Farm and GPS coordinates
301 survey responses 437 farm-location records

Join repeat._parent_index to main._index. A successful join adds response attributes to each location, but it also repeats those attributes across locations. Therefore 437 is a location-record count, while distinct surveyId gives 301 linked responses. Neither number alone establishes a unique-farmer or unique-farm count.

Review the source before drawing conclusions

Ten records share exact coordinates with another record. Retain them until a duplicate review establishes which represent the same farm. The crab location conflicts with the response-level activity, so show a verification note. The repeat-table area field has no specified unit; do not assume square metres or calculate a total area.

Request data and update the atlas

fetch requests the GeoJSON file asynchronously. await pauses the current async function until the requested operation finishes. It does not stop the whole browser. Always check the HTTP response and report failures so a missing file does not look like an empty survey.

Code example
async function loadData() {
  const response = await fetch('data/farms.geojson');
  if (!response.ok) throw new Error('Data request failed');
  return await response.json();
}

Filtering is a conjunction

The teaching atlas requires the district, activity and text conditions to match together. An empty district or activity selection allows all values. Counts and the list are based on the filtered subset; mapped count additionally requires valid point geometry.

Code example
return matchDistrict && matchActivity && matchText;

Avoid stale map layers

Clear the old layer, then add the filtered features. Populate selection options from unique values in allFeatures, so applying one filter does not unexpectedly remove valid choices from another control.

Serve the project over HTTP

Use a local web server while developing. Opening index.html directly as a file can block or complicate data requests. Read the browser Network panel to verify that farms.geojson returns HTTP 200, then use the Console to inspect JavaScript errors.

Worked result

Selecting Sea Cucumber Farm returns 18 location records. Clearing the controls returns 437 records associated with 301 responses. A search that matches nothing must show zero results and an explicit empty-state message.
