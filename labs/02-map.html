Display Zanzibar and a demonstration point

1. Replace starter/app.js with the code below. The same code is available in checkpoints/02_map.js. Keep only one app.js script reference in index.html.

Code example
const map = L.map('map').setView([-6.16, 39.38], 10);
L.tileLayer('https://tile.openstreetmap.org/{z}/{x}/{y}.png', {
  maxZoom: 19, attribution: '&copy; OpenStreetMap contributors'
}).addTo(map);
L.marker([-6.16, 39.38]).addTo(map)
  .bindPopup('Demonstration point only - not a surveyed farm.');

2. Reload through your local server. Drag the map and use the zoom controls. Click the marker. Its popup identifies it as a demonstration point, not a surveyed farm.

3. Identify three operations: creating the map, adding a tile layer, and adding a marker. The manual position arrays use latitude before longitude.

4. Change zoom 10 to 12, reload, and describe the difference. Restore the original value.

Checkpoint

The map displays Zanzibar with one illustrative marker and visible OpenStreetMap attribution. This marker must be removed when the real data is loaded in Lab 3.

Diagnose common failures

• L is not defined: Leaflet did not load, or app.js ran first.

• Map container not found: the HTML map id is missing or misspelled.

• Blank map space: check map height, tile network requests and internet access.

• Map container already initialized: do not load two map scripts together.

Student explanation

Explain why [-6.16, 39.38] is suitable for a Leaflet manual marker while [39.38, -6.16] belongs inside a GeoJSON geometry array.
