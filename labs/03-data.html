Read the survey features before mapping

1. Open data/farms.geojson in the editor. The root object is a FeatureCollection. Each feature has a geometry and properties. Inspect a real feature rather than replacing the data with invented farm locations.

Property Meaning
id Anonymous location code such as ZF-0001
surveyId Anonymous parent response code
type Activity from the repeat-location sheet
district and village Attributes joined from the parent response
area Reported value with unspecified unit
precision Reported GPS accuracy in metres
sharedLocation True when exact coordinates occur more than once

2. Observe that a geometry Point stores [longitude, latitude]. L.geoJSON reads that convention automatically. Do not reverse the dataset coordinates before loading it.

3. Confirm the expected controls: 437 location records; 301 distinct surveyId values; 407 seaweed, 18 sea cucumber, 1 crab and 11 unspecified activities.

Workbook route for advanced students

The kit includes prepare_geojson.py. It joins repeat._parent_index to main._index, exports anonymous properties and retains shared-coordinate records. Run it only with the supplied workbook schema. The original workbook is not inside the class kit.

Code example
python3 -m pip install openpyxl
python3 prepare_geojson.py survey.xlsx   --output starter/data/farms.geojson

Run the optional converter from the teaching-kit root; replace survey.xlsx with the actual workbook path. On Windows, use py instead of python3.

Fetch GeoJSON and draw the records

4. Replace app.js with checkpoints/03_markers.js. The reference below is the entire file. It replaces the Lab 2 script; do not append a second map initialisation.

Code example
const map = L.map('map').setView([-6.16, 39.38], 10);
L.tileLayer('https://tile.openstreetmap.org/{z}/{x}/{y}.png', {
  maxZoom: 19, attribution: '&copy; OpenStreetMap contributors'
}).addTo(map);
async function loadFarms() {
  try {
    const response = await fetch('data/farms.geojson');
    if (!response.ok) throw new Error(`Data HTTP ${response.status}`);
    const data = await response.json();
    const layer = L.geoJSON(data, {
      pointToLayer: (feature, latlng) => L.circleMarker(latlng, {
        radius: 6, color: '#098c78'
      }),
      onEachFeature: (feature, marker) => {
        const node = document.createElement('div');
        node.textContent = feature.properties.id + ' - ' +
          feature.properties.village;
        marker.bindPopup(node);
      }
    }).addTo(map);
    if (layer.getBounds().isValid()) map.fitBounds(layer.getBounds());
    document.getElementById('count').textContent =
      `${data.features.length} farm-location records loaded`;
  } catch (error) {
    document.getElementById('status').textContent = error.message;
  }
}
loadFarms();

5. Reload. Check that farms.geojson returns HTTP 200 in the Network panel. Click a point and read its anonymous code and village. The page reports 437 location records.

Checkpoint

The extent includes the survey points. A few markers overlap because some records share coordinates. Do not interpret visible symbol count as record count.
